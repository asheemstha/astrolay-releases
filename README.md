# Astrolay

Astrolay is a Mac app for editing, reviewing and publishing Astro websites.
This repository holds its releases only; the source is private.

## Install

In Terminal:

```bash
curl -fsSL https://github.com/asheemstha/astrolay-releases/releases/latest/download/install.sh | bash
```

It downloads the latest release, checks its SHA-256, installs Astrolay in /Applications (or ~/Applications) without asking for your password, and opens it.
Or download the `.dmg` from the [latest release](https://github.com/asheemstha/astrolay-releases/releases/latest).

Works on Apple Silicon and Intel Macs.

## Updates

Astrolay checks for updates on its own and offers them in the app. Every update is verified against a signing key built into Astrolay before it's installed.
